你好，我是杰杰

写代码、读杂书、偶尔把踩过的坑整理成文。这个站点是我公开的笔记本： 不追热点，不堆特效，只求读起来舒服、发得出去安全。

写什么

技术实践与安全运维笔记：静态站部署、Nginx、浏览器安全策略、日常排查记录。

生活与阅读：把书读薄的方法、走路时想到的事、对周遭细节的慢观察。

目标很简单：三个月后自己还能搜到当初的结论，并且愿意再读一遍。

此刻关注

  • 静态站点架构HTML / CSS / JS
  • Web 安全基线CSP · Headers
  • 服务器运维Nginx · TLS
  • 阅读与写作笔记方法

这个站点

纯静态多页站点，无构建依赖、无第三方脚本，方便直接丢到云服务器或对象存储。

默认浅色为宣纸色，支持系统深色偏好与手动切换；正文行宽控制在舒适阅读范围。

安全默认值写在 nginx/site.conf 与 SECURITY.md，部署时照着勾选即可。
